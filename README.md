# Travel Weather Planner

Travel Weather Planner is a web application that displays current weather conditions and exchange rates for 1,000 FCFA across 20 cities in 10 countries. It is designed for travelers and anyone who wants to explore destinations, compare weather conditions, and check currency conversions before traveling.

## Features

- Current weather information for 20 cities.
- Currency conversion of 1,000 FCFA into each country's local currency.
- Search for cities by name.
- Filter destinations by country.
- Sort cities by name or temperature.
- Dynamic summary displaying the total number of cities and countries, the hottest city, and the coldest city.
- Error handling for unavailable weather data, exchange rate API failures, and searches with no results.
- Responsive design adapted for mobile devices.
